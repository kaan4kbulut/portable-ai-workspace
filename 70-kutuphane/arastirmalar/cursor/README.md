# cursor — Cursor (Anysphere) incelemeleri

**Girer:** Cursor'un mimarisi, özellikleri, güvenlik olayları ve atölyeyle karşılaştırmalar; yalnız herkese açık kaynaklar ve kurulu paketin dışarıdan görünen yapısı.
**Girmez:** derlenmiş koddan çıkarılmış içerik, Cursor kimlik/oturum dosyaları, uygulama kodu (→ `20-sistem/`), kararlar (→ `60-hafiza/kararlar/`).
