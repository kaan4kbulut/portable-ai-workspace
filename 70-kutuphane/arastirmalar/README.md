# arastirmalar — kaynaklı araştırma raporları

`/kutuphane <konu>` ve iş bölümüyle (Codex, agy) yürütülen araştırmaların raporları. Konu başına klasör,
rapor adı `YYYY-MM-DD-<ad>.md`. Her raporun ikinci satırı `Kaynak denetimi:` olur; yeni rapor `DIZIN.md`'ye eklenir.

**Girer:** kaynaklı, tarihli araştırma raporu. **Girmez:** karar (→ `60-hafiza/kararlar/`), ham indirme (→ `90-gelen-kutusu/`),
kalıcı model kartı (→ `../modeller/`).
