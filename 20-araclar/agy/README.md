# 20-araclar/agy (Antigravity CLI)

Proje içinde `AGENTS.md` okuduğu önceki kullanımda görüldü; global talimat dosyasının yeri **doğrulanmadı** (Aşama 2:
`agy --help`, belgeler). MCP: `~/.gemini/config/mcp_config.json` → `genel/mcp_config.json` (`kur.sh --genel`; agy'nin bunu
okuduğu doğrulanınca). İzin kipi TURBO (sandbox kapalı) kullanıcı kararıdır; sunucuya taşınırken yeniden değerlendirilir.
Makine-yerel: `~/.gemini/{antigravity/,antigravity-cli/,config/{projects,node_modules,config.json}}`.
