# istemler/

Kütüphaneci işçilerine verilen istem şablonları, iş türü başına bir dosya (`{{konu}} {{katman}} {{neden}} {{dosyalar}}` yer tutucuları).
Ad: iş türünün tireli hali (`sayfa_yaz` → `sayfa-yaz.md`).

**Girer:** istem şablonu. **Girmez:** çalışma çıktısı (→ `20-sistem/durum/<host>/kutuphaneci/`), rapor (→ `70-kutuphane/`).
