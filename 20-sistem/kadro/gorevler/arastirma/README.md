# arastirma

## Girer

`istem.md`, `degerlendir.py`, `girdi.json`, `cozum.json` ve varsa `rubrik.md`.
Manifestolar göreli dosya yollarını metin içeriğine eşler; alt klasör açılmaz.
Dosya adları kebab-case, Python modül adları İngilizcedir.

## Girmez

Model sonuçları ve kota kayıtları. Çözüm ve değerlendirme dosyaları modele verilmez.

## Çalıştırma

Depo kökünden `python3 -I -B 20-sistem/kadro/gorevler/arastirma/degerlendir.py calisma`.
