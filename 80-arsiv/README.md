# 80-arsiv — Arşiv

"Taşı, silme" (ANAYASA 6.4). Kaldırılan her şey `YYYY-MM-DD-<ad>/` klasörüne, içinde `NEDEN.md` (ne, neden, geri alma koşulu;
şablon `00-cekirdek/sablonlar/belge/neden.md`). Git geçmişi zaten vardır; arşiv, "bir daha aynı şeyi açma" uyarısı için insan-okur katmandır.
Yeni bir şey açmadan önce burada ara.

**Girer:** emekli dosya/klasör + NEDEN.md. **Girmez:** çöp (log, geçici çıktı: silinir), 50 MB üstü dosya (→ `30-programlar/dis-kaynaklar/`).
